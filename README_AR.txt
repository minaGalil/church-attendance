إضافة وتعديل بيانات الشباب — خدمة متوسط بنين

1) افتح Supabase > SQL Editor وشغّل ملف 01_secure_youth_api.sql مرة واحدة.
2) ارفع app.js وindex.html وstyle.css فقط إلى جذر GitHub Repository واستبدل الملفات القديمة.
3) لا تغيّر config.js أو ملفات الصور.
4) انتظر GitHub Pages ثم Ctrl+F5.
5) افتح إدارة الشباب، جرّب إضافة شاب برقم بصمة جديد ثم تعديله.

أمان: لا تستخدم service_role في المتصفح. الحفظ يتم عبر RPC تفحص الحساب الفعّال والدور والفصل. لا توجد صلاحية حذف. يجب اختبار الأدوار بعد التنفيذ.
