تحديث استيراد DAT الأسبوعي — خدمة متوسط بنين
1) شغّل ملف 02_secure_dat_import.sql في Supabase SQL Editor مرة واحدة.
2) ارفع index.html وapp.js وstyle.css إلى GitHub واستبدل النسخ القديمة. لا تغيّر config.js أو الصور.
3) افتح البرنامج وسجّل دخول Super Admin أو Church Admin أو Attendance Manager.
4) افتح «استيراد ملف البصمة DAT»، اختر الملف، راجع الأعداد، ثم اضغط «استيراد البصمات».
5) إذا رُفع الملف مرتين، تتجاهل الدالة بصمات USERID+CHECKTIME+SENSORID الموجودة بالفعل، بما فيها الأرقام غير المسجلة في USERINFO.
6) لا تمنح INSERT مباشر لجدول checkinout للمستخدمين. كل الحفظ يتم عبر دالة محمية تتحقق من الصلاحيات.
7) يجب أن يكون الملف النصي TAB-delimited بستة أعمدة: USERID, CHECKTIME, SENSORID, CHECKTYPE, VERIFYCODE, WorkCode.
8) التواريخ تُخزن كما وردت من الجهاز بدون تحويل منطقة زمنية.
9) الاستيراد على دفعات 200؛ إذا فشل في منتصف العملية يمكن إعادة الملف بأمان.
10) بعد الرفع راجع تقرير الحضور وتقرير البصمات غير المسجلة.
