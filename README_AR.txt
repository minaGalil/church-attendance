خدمة متوسط بنين — كاتدرائية مارمرقس الرسول بالكويت

النسخة الثانية: شاشة عربية RTL + شعار الكنيسة + أسماء الفصول + فلاتر البحث والتاريخ + تصدير CSV عربي.

التحديث على GitHub:
1) افتح المستودع minaGalil/church-attendance.
2) ارفع الملفات index.html, app.js, style.css, Logo4.png (استبدال الملفات القديمة بنفس الأسماء).
3) اترك config.js الحالي في GitHub كما هو إذا كنت قد وضعت فيه Project URL وPublishable Key.
4) انتظر نشر GitHub Pages ثم اضغط Ctrl+F5 لتحديث الصفحة.

ملاحظات:
- شاشة الشباب تعرض أسماء الفصول من جدول DEPARTMENTS، وليس أرقام الفصول.
- الفلاتر تعمل على البيانات المقروءة المسموح بها حسب RLS.
- عرض الحضور للوالدين يقتصر على ما تسمح به RLS.
- تقرير البصمات غير المسجلة يحتاج API آمن، وهو غير مفعل في هذه النسخة.
- البرنامج للقراءة والتصدير حالياً؛ لم يتم فتح تعديل البيانات.
- لا ترفع ملفات بيانات الشباب أو مفاتيح service_role/secret إلى GitHub.
