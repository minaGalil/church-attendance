خدمة متوسط بنين — النسخة الثالثة
1. احتفظ بملف config.js الموجود عندك لو متصل بالفعل بـ Supabase، ولا تستبدله بملف الإعدادات الافتراضي.
2. ارفع الملفات index.html وapp.js وstyle.css وbanner.png وchurch-logo.png وservice-logo.png إلى جذر GitHub Repository.
3. افتح GitHub Pages واضغط Ctrl+F5.
4. استخدم فقط Publishable/anon Key في المتصفح، ولا ترفع Secret Key أو service_role أو بيانات الشباب.
5. هذه نسخة واجهة قراءة وفلاتر وتقارير CSV/طباعة؛ إدارة المستخدمين وتعديل البيانات يحتاجان API آمنة.
6. القراءة مقيدة بسياسات RLS الفعلية في Supabase.
